## Remaining measurement gates

`Flow upgrade matched measurements` accepts an immutable candidate build run and
verifies the stable 1.0.1 baseline checksum, attestation and exact source commit.
Profiles, transport buffers and optional scheduling experiments run separately.
Each scenario uses five rotated repeats of the same fixture and startup reserve.
Reports include startup/delivery tail waits, seek TTFB, native redundant bytes,
CPU, RSS, cache usage and verified Range integrity. Percentiles from five repeats
are empirical observations with five samples, not precise population estimates.

`build/resource_endurance.py` owns its server, ports and state and reads verified
generated bytes through the real native peer path. It records RSS, handles,
goroutines and cache reservations while cycling readers and seeks. Only a real
completed run of at least eight hours with known convergence evidence can set
`eight_hour_acceptance`. Short smoke runs cannot meet that acceptance gate.
Eight-hour execution is still pending.
